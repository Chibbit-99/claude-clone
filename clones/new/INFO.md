## Info about extracted files
* add: the new chat page with the add popup which appears when the plus button is clicked
* addaddtoproject: the new chat page with the add to project menu on the add popup when the add to project button is hovered
* addconnectors: the new chat page with the add connectors on the add popup when the add connectors button is hovered
* adddesignsystem: the new chat page with the add design system menu on the add popup when the add design system button is hovered
* addskills: the new chat page with the add skills menu on the add popup when the add skills button is hovered
* cowork: the new chat page with the cowork popup which shows when the cowork button is clicked
* index: the new chat page
* modelselect: the new chat page with the model selector menu which appears when the model name is clicked (Here it is Haiku 5.5 Low)
* modelselecteffort: the new chat page with the effort selection menu on the model selector menu which appears when the effort menu is hovered
* modelselectmore: the new chat page with the more models selection menu on the model selector menu which appears when the more models menu is hovered
* newproject: the new chat page with the add to project popup which appears when the new project button is clicked on add to project menu in the add menu
* suggestions: the new chat page with the suggestions menu which appears when one of the suggestions buttons are clicked such as "write" "learn" "code" "life stuff" "claude's choice"
* upload: the new chat page with the upload files popup which appears when the upload or add files button is clicked on the add menu
* workinginproject: the new chat page with an icon signifying a user has chosen a project to work in from the add to project menu on the add popup.
